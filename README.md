# FotoViva Pages — prévia pública

Demonstração **visual e interativa** da FotoViva, disponível em:

https://pedromatosx.github.io/fotoviva-pages/

O código-fonte completo da aplicação permanece no repositório privado `pedromatosx/fotoviva`. Este repositório contém somente os arquivos estáticos compilados e os scripts públicos exclusivos da demonstração.

## Experiências disponíveis

- Explorar eventos e galerias com dados fictícios.
- Testar carrinho, descontos e fluxo de compra **sem nenhum pagamento**.
- Usar o roteiro **Como testar** para navegar pelas telas.
- Criar álbuns locais na área do fotógrafo; marcar rascunho/publicado.
- Escolher JPEGs: prévias `blob:` são criadas no navegador, **sem enviar fotos para nenhum servidor**.

Álbuns demonstrativos ficam em armazenamento local deste navegador. Imagens escolhidas são temporárias e desaparecem ao fechar/recarregar a página. O botão **Reiniciar demonstração** limpa os dados locais desta prévia.

Não existe conta real, upload na nuvem, pagamento, biometria, entrega de originais ou vínculo com Cloudflare/Supabase nesta versão. Nenhum dado real ou credencial deve ser armazenado neste repositório.
